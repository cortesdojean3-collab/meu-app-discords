Perguntas frequentes

O que fazer quando não há instalador?

Use “Abrir e instalar o PWA”. As opções nativas ficam indisponíveis até existir um arquivo válido em uma versão publicada.

Como instalar no celular?

O site pode ser instalado pelo navegador: no Android, use o menu do Chrome e escolha “Instalar app”; no iPhone, use Compartilhar no Safari e “Adicionar à Tela de Início”. Não há APK ou versão da App Store publicada aqui.

O Windows mostra um aviso?

O instalador atual não é assinado digitalmente. O Windows pode exibir o SmartScreen. Instale somente se você confia na origem do arquivo.

O macOS bloqueia o aplicativo?

Os builds não têm assinatura ou notarização. O macOS pode exigir que você autorize a abertura nas configurações de Privacidade e Segurança.

Os dados de versão e tamanho vêm dos arquivos da versão mais recente do GitHub Releases. A página não mostra plataformas sem um arquivo publicado.
